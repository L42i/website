# Keeping Score(s)

**October 3, 2026** · SITE Festival, The Goat Farm, Atlanta, Georgia
*Performance / installation / audience participation*

![](/assets/events/keeping-scores-2026/1.jpg)

L42i and Georgia Tech School of Music musicians presented Keeping Score(s), a performance-installation centered on experimental scores and participatory listening. The program combined the score-printing concept Timbres with Ensonification, a browser-based interface for data-driven sonification scores. The event was designed as an extended public format with repeated ensemble sets, playback, and audience participation across the evening.
