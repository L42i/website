# WeSp

WeSp is a browser-based interface for **real-time collaborative trajectory editing** in immersive audio. Trajectories are 3D splines through the virtual acoustic scene, traversed by playheads that carry sound objects along them at adjustable speed and direction. Several people can edit the same set of trajectories at once, so a group builds and performs a spatial scene together rather than one person automating it alone.

![](/assets/projects/wesp/interaction_concept.png)

The design separates what is shared from what is not. **Trajectories are collective**: any participant can reshape any path, and changes appear immediately for everyone. **Sound objects are individual**: each performer controls only their own, which avoids conflicts and keeps a clear sense of personal agency inside the shared structure. Objects are colour-coded per user, with your own drawn prominently and everyone else's held back in transparency, so the scene stays readable as it fills up.


Developed by Lennart Sailer (Audio Communication Group, TU Berlin) and [Henrik von Coler](/people/henrik-von-coler).
